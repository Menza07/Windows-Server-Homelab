### Adding the Backup Disk
1. Added second 20 GB virtual disk in VMware
2. Brought disk online
3. Initialized as **MBR**
4. Created simple volume
5. Assigned drive letter **E:**
6. Formatted as **NTFS**
7. Volume name: `FS01-Backup`

## CompanyData File Share

| Setting       | Value                  |
|---------------|------------------------|
| Local Path    | `C:\CompanyData`       |
| Share Name    | `CompanyData`          |
| Protocol      | SMB                    |
| SMB Permission| Everyone — Allow — Full|

> SMB permissions control network access.  
> NTFS permissions control actual file-system access.

### NTFS Permissions on `C:\CompanyData`

Principals present:
- Creator Owner
- SYSTEM
- Domain Users
- Administrator

**Domain Users** at the root have: **Read & Execute**

### Public Folder

Path: `C:\CompanyData\Public`

- Domain Users: **Modify**
- Inheritance is **disabled** (allows different permissions from the parent)
- Access fully tested from WIN10-01:
  - Creating files ✅
  - Editing files ✅
  - Deleting files ✅
