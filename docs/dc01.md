```
Forest: homelab.local

    └── DC01 (192.168.59.10)
```

### Promotion Details
- Option selected: **Add a new forest**
- Root domain name: `homelab.local`

Windows automatically created:
- Active Directory database
- SYSVOL
- NETLOGON
- DNS integration
- Domain security infrastructure
- Default AD containers and Organizational Units
